# Implementation Learnings
1. To run code -
```
javac <CLASSNAME>.java
java <CLASSNAME>
```
2. All java files that are part of the program need to be compiled (with javac) before running the program.
A Shortcut command -
```
javac <PACKAGENAME>/*.java
java <PACKAGENAME>.CLIENT_CODE
```

3. In Java, if an interface or class is declared as public, it must be placed in a file with the same name as the interface or class
